# 04. 사진·항공 판독

## 로드뷰
- 지점 간격을 정해(예: 22지점) 지점마다 2방향(가로 방향·건물 정면). 촬영 연월을 기록.
- **사람 행태**: 보행·정지·앉음·대화·작업 등으로 센다. 인접 지점·양방향에 같은 사람이 찍히면 한 번만(실사례: 중복 제거로 60→46명).
- **녹시율(GVI)**: 초록 화소 비율. 실제 쓴 규칙 예: HSV 색상 65~170°·채도 ≥ 0.15·명도 ≥ 0.06, 노란 차선(20~60°) 제외, 화면 UI 영역 마스크. 그늘진 잎은 들어가고 회녹색 지붕·간판이 일부 섞일 수 있음을 각주로.
- **전면공간**: 필지선 ↔ 건물 전면 사이 쓰임(주차·적치·화분·좌석·비어 있음)과 단차. 깊이는 판독 추정, 실측은 현장.

## 항공사진(스카이뷰)
- 보도·차로·식재대 폭: ±0.3~1 m 오차 명기.
- 주차 면수: 구획선 판독 + 장소 정보. 「추정/판독」을 구분해 표기.

## 답사사진
- 남→북(또는 동선) 순서로 정렬, 건물 번호와 짝지음(추정이면 「현장 확인」).
- 야간 사진은 간판·조명·영업 여부 판독에 쓴다.

## 표본 확인 (필수)
자동 규칙을 전체에 돌리기 전 표본 5~10장을 결과 마스크와 나란히 본다. 실패 사례: 위성사진 초록 판정이 지붕까지 90% 초록으로 나와 규칙 폐기·재작성.
