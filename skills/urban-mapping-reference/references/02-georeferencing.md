# 02. 좌표 정합

## 교수 PDF → 실제 좌표
1. PDF 가 벡터인지 확인(PyMuPDF `page.get_drawings()` 가 도형을 내면 벡터).
2. 여러 PDF 의 같은 건물 폴리곤은 **모양 서명**(면적·둘레·꼭짓점 수·외접 사각형 비)으로 대응쌍을 찾는다. 실사례: 1,825쌍, 잔차 0.
3. 대상지 경계 같은 선은 라벨 위치로 맞춘다(실사례: 라벨 12개, 잔차 0.2 pt).
4. 도면 좌표(pt)를 m 로: 축척 막대 길이로 환산(예 1,134 pt = 1,000 m).
5. OSM 건물과 위상상관으로 EPSG:5186 에 붙인다. 검증 = 주요 가로 중심선 차이(예 0.6 m, 4.4 m)를 적는다.

## 사진·위성 → 도면
- 위성사진은 Esri 타일과 윤곽 상관(OpenCV)으로 1차 정합 → 수치지형도 건물 윤곽으로 미세 보정.
- 결과 격자를 `npz` 로 저장해 시트마다 다시 쓰지 않는다.

## 기록
변환 행렬·대응쌍 수·잔차·기준선 차이를 `SOURCES.md` 의 해당 레이어 줄에. 잔차를 안 적은 정합은 끝나지 않은 것.
