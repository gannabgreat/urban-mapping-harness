# 01. 한국 공공데이터 출처 (레이어별)

키는 환경변수·키체인에서 읽는다. 코드·커밋·로그에 남기지 마라.

| 레이어 | 출처 | 방법·함정 |
|---|---|---|
| 건물·도로 바탕 | 교수 제공 현황도(수치지형도·건축물정보), 가로규모현황도 | QGIS 벡터 PDF 면 PyMuPDF 로 도형·채움색 직접 추출. 범례색 ↔ 채움색 매칭으로 용도·노후도·층수 |
| 노후도·층수 빈칸 | 공공데이터포털 건축HUB 건축물대장 **표제부** `apis.data.go.kr/1613000/BldRgstHubService/getBrTitleInfo` | 필지 PNU(시군구·법정동·번·지)로 조회. 한 필지에 여러 동이면 동명칭·면적으로 짝짓기. 0건은 「없음」이 아니라 PNU 오류 의심 |
| 필지·지목 | 토지이음 `eum.go.kr` 필지 조회 | 필지↔건물 짝짓기, 빈 땅 지목(대·공원·도로·학교) |
| 용도지역·지구 | 서울 열린데이터광장 도시계획 공간정보(UPIS SHP) + 토지이음 토지이용계획 | SHP 좌표계 확인(EPSG:5186/5174) |
| 지구단위계획 높이 | 해당 지구단위계획 결정도서 높이계획도 | 도서 그림을 구역계에 정합(02 참고) 후 현재 층수와 대조 |
| 지형 | Copernicus GLO-30 DSM | 30 m 격자라 골목 단차는 못 잡는다 — 「지형 경향」까지만 |
| 도로·대중교통 보조 | OpenStreetMap(Overpass) | 일방통행·정류장·역 출입구·횡단보도·주차장·공공자전거. 기준일 명기 |
| 가게·숙소 변화 | 행정안전부 지방행정 인허가데이터(LOCALDATA) `file.localdata.go.kr` | 업종 파일 일괄 다운로드 → 좌표로 대상지 클립. 개업·폐업일로 시계열 |
| 학교·기관·공원 | 카카오 로컬 장소검색 API `dapi.kakao.com/v2/local/search/` | 카테고리·키워드 검색, 반경·페이지 끝까지. 주소 → 좌표 지오코딩도 여기 |
| 가로 치수·주차면 | 카카오맵 스카이뷰 항공사진 판독 | 오차 ±0.3~1 m 명기. 주차는 구획선 판독 + 장소 정보 |
| 사람 행태·녹시율·전면공간 | 카카오맵 로드뷰 | 지점×방향×촬영연월 기록(04 참고) |
| 수목(위에서 본 녹지) | 수업 제공 정사사진, 없으면 Esri World Imagery 타일 | 좌표 정합 후 초록 판정, 표본 확인 필수 |
| 축척 요소(사람·차·나무) | Openclipart (CC0) | 출처 id 를 SOURCES.md 에 |

## 공통 함정
- 0건·빈 응답 = 실패. 요청 파라미터(키 제외)와 응답 코드를 남기고 다시 본다.
- 데이터마다 기준일이 다르다(수치지형도 2025 vs 대장 2026 vs 로드뷰 2026-07). 시트 각주에 같이 적는다.
- 주소 지오코딩 결과는 가장 가까운 건물 윤곽에 스냅하고, 매칭 수(예 22/23)를 적는다. 번호는 현장 확인.
