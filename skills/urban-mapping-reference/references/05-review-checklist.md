# 05. 검토 체크리스트 (실제로 걸린 것들)

## 1·2차 (데이터 대조)
- 축척 표기 ↔ 실제 축척 불일치
- 사실과 다른 문장(역 출입구 위치·일방통행·정류장 수)
- 같은 장면 중복 집계(밤 60→46명)
- 단면 높이가 층수·층고 가정과 안 맞음(H/W 재계산)
- 같은 지점이 두 시트에서 다르게 쓰임(야간 중복)

## 3차 (맥락 없는 검수자)
- 교안 항목 누락(가로입면도 → 신설)
- 막다른 길·덩어리 수 재계산
- 기본도 층수·연도 자료의 한계 각주 누락
- 결론 범위가 분석보다 넓음(논리 좁히기)

## 4차 (다른 세션 독립 검토)
- 같은 개념의 판정 기준이 시트마다 다름: 「골목」을 건물 기준으로 통일 → 식음 업소 골목 비율 79→62%
- 조사표에 없던 첫 줄 건물(8동) 표시
- 층고 가정 통일(H/W 0.37 등)
- 역세권 기준(역 중심 vs 출입구)

## 반영 원칙
지적을 그대로 받지 않는다. 데이터로 재계산 → 맞으면 반영, 틀리면 기각 사유 기록. 차수마다 반영·기각·확인 못 함 건수를 남긴다.
