## 평단면 구성 원칙
건물면~담장 전폭을 구역(보도·식재대·차로·자전거·보도·담장)으로 나눠 각 폭 표기 → 단면 아래 같은 축으로 평면 → 단면선 A–A′ → 사람 1.7 m·승용차 4.4 m 축척 요소 → 재료·H/W. 건물은 절단 단면(포셰), 층별 용도 글자.
