# Urban Mapping Harness — 오케스트레이션

## 불변 원칙 (요약 — 전문은 SPEC §2)
1. 데이터 → 코드 → 시트. 손으로 그리지 않는다.
2. 문장 속 숫자 = 계산값.
3. 못 읽으면 `판독 불가`·`현장 확인`. 0·빈 결과를 「없음」으로 쓰지 않는다.
4. 레이어마다 출처·기준일.
5. 추정은 추정이라고(오차범위).
6. 만든 쪽 ≠ 검토하는 쪽. 4차 검토 통과가 제출 조건.
7. 자동 판정은 표본 확인 후.
8. git 으로 롤백 가능하게.
9. 시트 결론은 `CONCLUSION.md` 하나로 귀결(근거 시트·데이터 파일 필수).
10. 사람 판단은 🔲 미결정(CONCLUSION.md), 현장 실측은 FIELD_TODO.md.

## 에이전트 (이 플러그인의 agents/)
- **collector** 수집 · **georef** 좌표 정합 · **reader** 사진·항공 판독 · **cartographer** 작도
- **verify** 검토 1·2차 · **blind-critic** 검토 3차(맥락 0) · **field** 현장 확인 목록
본체(오케스트레이터)는 Agent 도구로 위임하고, 결과를 **직접 검증한 뒤에만** 쓴다(숫자 무작위 대조·PNG 직접 보기).

## 시트 파이프라인 (/um-sheet)
교안 항목 확인 → 수집 → 정합(잔차) → 판독(표본 확인) → 작도(계산값, `scripts/sheet_template.py` 견본에서 시작) → 본체 확인 → 결론을 `CONCLUSION.md` 에 반영 → 상태 `초안` → 커밋.

## 검토 게이트 (/um-review)
1·2차 verify → 3차 blind-critic → 4차 외부 독립 검토. 지적은 재계산 후 반영/기각, `_state/review-log.json`. 4차 기록 전에는 훅이 「제출」 전환을 막는다.

## 피드백 반영
수업 피드백은 `CLAUDE.md` 「피드백」 절에 **원문 그대로** 날짜와 함께 적는다. 시트 번호가 바뀌면 `sheets/SHEETS.md` 를 먼저 고친다. 사람이 「롤백」이라고 하면 해당 커밋을 되돌리고 이유를 남긴다.
